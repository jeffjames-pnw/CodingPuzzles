# CodingPuzzles

I enjoy solving coding puzzles for fun and am sometimes required to do so during interviews. I've archived here some of my solutions for posterity.

I typically code in Python but also enjoy PowerShell and have used these puzzles to remember other languages, such as Go or C++.


## LeetCode

The best source for traditional coding problems is https://LeetCode.com/problemset. 

When needing a fix, I'll pick a "Hard" problem with a low acceptance rate. The problems with the lowest acceptance rate typically require insightful optimizations beyond the initial algorithm.
